How to use this Add-in expand_more

1. Connect: Paste your Finnoto Bearer token. Optionally set a custom instance URL (e.g. abdebug.finnoto.dev).

2. Pick a report: Search or scroll the report list. Select the report.

3. Select sheets: Check the sheet(s) you want. Each sheet lands in its own Excel worksheet.

4. Date & Filters: Pick a date preset or a custom range. Add key→value filter pairs if needed.

5. Fetch: Click Fetch Report — data streams into Excel.
