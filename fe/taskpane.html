How to use this Add-in

1. Fetching Data: Select a collection, enter a JSON filter query (or leave empty for all), and click Sync & Fetch Data.

2. Inserting Data: To insert new records, append them as new rows at the bottom of the table in your worksheet. Leave the _id cell empty.

3. Updating Data: Modify cells in rows that have an _id value. Clicking Sync & Fetch Data will push those edits back to MongoDB.

4. Filter Queries: Standard MongoDB query filter format only, e.g. {"age": {"$gte": 30}}.
