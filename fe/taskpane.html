How to use this Add-in

1. Fetching: Select a collection, build a filter (or leave empty for all), click Sync & Fetch.

2. Inserting: Import schema first via ⬇ Schema, then add rows below the headers.

3. Updating: Modify cells in rows that have an _id. Sync pushes edits to MongoDB.

4. Builder vs JSON: Builder generates the filter visually. Switch to JSON to hand-write complex queries.
